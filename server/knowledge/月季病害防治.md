# 月季白粉病家庭防治手册

白粉病是月季最常见的真菌病害，多发生在春秋两季通风不良、湿度高的环境。叶片正面会出现白色粉状霉层，严重时嫩梢扭曲、花苞打不开。

## 早期识别
发病初期叶片出现零星白粉斑点，像撒了一层面粉。这个时候是最佳防治窗口期，拖到全叶覆盖后治疗难度翻倍。

## 家庭用药方案（优先级从高到低）

### 方案一：酒精擦拭法（仅限1-2片叶早期）
用75%医用棉球轻轻擦拭病斑，每天一次，连续3天。适合阳台只有一两盆、不想买药的玩家。注意只擦叶片正面，不要漏掉叶背。

### 方案二：三唑酮（粉锈宁）
这是白粉病特效药。家庭剂量：1克药粉兑1.5升水（约3瓶矿泉水）。用细雾喷壶均匀喷湿叶片正反面，尤其是叶背。间隔7天一次，连续2-3次。最后一次喷药后15天再赏花。

### 方案三：戊唑醇
和三唑酮轮换使用，避免抗药性。1毫升药液兑1升水。这个药有点内吸性，灌根也能起到预防作用。但灌根浓度要减半，否则容易烧根。

## 物理辅助措施
- 立即摘除严重病叶，装进塑料袋密封后扔，不要丢在花盆里
- 把花盆挪到通风最好的位置，电扇对着吹都行
- 早晨浇水，给足时间让叶面在傍晚前干透
- 氮肥停一停，改施磷钾肥让枝条老熟

## 禁忌
白粉病爆发期不要往叶面上喷水冲"粉"，水会帮助孢子扩散。也不要用牛奶兑水喷，网络偏方对月季白粉基本无效，还会堵塞气孔。
